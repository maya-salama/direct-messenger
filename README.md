# Distributed Social Messenger

A desktop direct messaging application built with **Python** and **Tkinter** for the DSP platform. Users can create profiles, configure a server, add contacts, and send and receive messages through a graphical interface.

## Features

* Create user profiles
* Configure and connect to the DSP server
* Add contacts
* Send and receive direct messages
* Tkinter-based desktop GUI
* Chat-style message display

## Technologies

* Python
* Tkinter
* DSP Server

## How to Run

Run the server in one terminal:

```bash
python server.py
```

Then, in a separate terminal, launch the application:

```bash
python a4.py
```

The application window will open automatically.

## How to Use

1. Use **File** to create a profile.
2. Use **Settings** to configure the DSP server and add contacts.
3. Type a message in the text box and click **Send**.
4. Sent messages appear on the **right**, while received messages appear on the **left**.
